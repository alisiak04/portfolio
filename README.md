# alisiakazimierek.com

Portfolio site — Vite + React, dark editor-themed design, deployed to GitHub Pages.

## Run locally

```bash
npm install
npm run dev
```

## Structure

```
src/
  components/
    Nav.jsx           nav bar
    Hero.jsx           typed intro, code-editor window
    About.jsx           course + internship/project framing
    Experience.jsx      4 internships, from the CV
    Projects.jsx         software / hardware split, solo vs team
    Achievements.jsx
    Footer.jsx
    CircuitField.jsx     cursor-reactive circuit-trace background (signature art)
  index.css              design tokens (colors, type, editor chrome)
```
